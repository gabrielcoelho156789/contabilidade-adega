Publicar na Vercel (Acesso Online)

Este painel está pronto em um único arquivo HTML para você colocar no ar gratuitamente:

1. Salve o arquivo

Crie uma pasta no seu computador e salve este código com o nome exato index.html.

2. Suba na Vercel

Acesse vercel.com, entre com sua conta (GitHub, GitLab ou e-mail), clique em Add New Project e envie a pasta. Você receberá um link .vercel.app para acessar pelo celular ou computador.

3. Sincronização em Nuvem Ativada

Seus lançamentos agora sincronizam automaticamente em tempo real! Para conectar sua própria conta gratuita na nuvem após subir na Vercel, basta substituir os dados de DEFAULT_CLOUD_CONFIG no início do script pelo seu projeto.
